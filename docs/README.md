# رسَّام | Rassam

**Arabic-first virtual whiteboard for hand-drawn diagrams**

Rassam (رسَّام) is a complete, open-source, Arabic-first clone of Excalidraw that includes **every feature of the official editor and the hosted application**, plus deep RTL and Arabic-language optimizations.

- **License**: MIT
- **Default language**: Arabic (RTL)
- **Core**: Full Excalidraw editor + real-time collaboration + E2E encryption + shareable links + PWA + self-hosted persistence

## Why Rassam?

Excalidraw is excellent, but:

1. English is the primary experience.
2. Self-hosted collaboration requires significant extra work.
3. Arabic typography and RTL polishing are incomplete for native-feeling use.

Rassam starts from the official monorepo, makes Arabic the default, hardens the full collaboration stack for self-hosting, and adds first-class Arabic fonts and RTL behavior.
