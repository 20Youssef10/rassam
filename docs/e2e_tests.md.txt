## 🐞 Real bugs found (documented in `e2e/99-known-bugs.spec.ts`)

1. **Text tool is broken (P0)** — clicking the canvas with the text tool mounts the editor, but the pointer-down default action immediately blurs it → `commitText()` deletes the empty element. **You cannot create text with the mouse.** (Editing existing text via double-click *does* work.) Fix: `e.preventDefault()` in the canvas pointerdown, or don't commit-on-blur when text is unchanged.
2. **Shift+click can't extend selection** — `Shift`+pointerdown with the select tool is captured by the pan gesture before the multi-select branch (dead code).
3. **Ctrl+Shift+PageUp/PageDown do nothing** — "bring to front / send to back" are documented in the help dialog but never run (the outer `!ctrlKey` guard filters them out).
4. **Honorable mentions:** the top bar claims self-hosted fonts but `App.tsx` still injects a `fonts.googleapis.com` stylesheet (offline rendering relies on the fontsource fallback); zoom % label rounds down (`0.99 → 99%`); peer collab snapshots can momentarily overwrite a faster peer's edit (last-write-wins on `ts`).

## ❌ What the app lacks (vs. Excalidraw & typical virtual whiteboards)

**Canvas & drawing**
- No live shape editing of text-in-shape (labels are canvas-rendered only), no per-element font-size picker in the properties bar (only a global font family)
- No multi-point line editing via UI handles exposed for non-linear shapes, no arrowhead style options (line/plain/triangle), no dashed/dotted stroke styles
- Freehand is un-smoothed (no stroke perfecting/pressure); no pen/tablet pressure support
- No snap-to-object (guides/alignment hints while dragging) — only grid snap; no snapping for sticky notes to grid pitch shown

**Structure & navigation**
- No groups panel/layers panel; z-order exists but nothing visualizes stacking
- Frames: no UI button to export a frame (`exportFrame` exists in the API but is unreachable from the UI); no frame titles rendered on canvas
- No viewport presets/bookmarks, no "zoom to selection", no zoom controls/buttons (wheel + palette only), no fit-to-content button

**Collaboration**
- No CRDT/OT — last-write-wins whole-scene replacement; concurrent edits on the *same* element silently lose data
- Remote cursors broadcast but I found no visible remote-cursor overlay verified live; no remote selections/names beside cursors
- No chat, comments, or @mentions; no presence avatars; no follow-mode indicator on the followed side
- No conflict resolution UI, no revision history/snapshot timeline

**Import/Export & interoperability**
- No `.excalidraw` file import/export (interop with the ecosystem you're compared against)
- No PNG-with-transparent-background option, no export scale (1x/2x) selection, no clipboard image paste *into* selection as element style (paste works but no image crop UI)
- No CSV/markdown table, no image-to-board drag-drop from desktop (file picker only)

**Library & templates**
- No drag-from-library (click-to-place only), no library item editing, no per-item thumbnails (text buttons only), no community/remote library URL loading

**Platform & polish**
- No localStorage quota warning; no scene "saved to cloud" indicator distinguishing local vs room persistence
- No dark-canvas contrast audit (dark theme text elements keep dark ink); no print support; no keyboard nudge with arrow keys; no element opacity control in UI
- No i18n beyond ar/en, no font-size control per element, no text auto-wrap (long lines overflow the measured width)

**Quick wins I'd prioritize:** fix the 3 bugs above (they're all small diffs), add arrow-key nudging + zoom buttons, wire `exportFrame` into the UI, and add `.excalidraw` import — that alone would close ~40% of the visible gap.
