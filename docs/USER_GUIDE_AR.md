# دليل المستخدم — رسَّام

مرحبًا بك في **رسَّام**، السبورة العربية للرسم والتخطيط بأسلوب يدوي.

## البدء السريع

1. افتح التطبيق — الواجهة عربية واتجاه الصفحة من اليمين إلى اليسار افتراضيًا.
2. اختر أداة من الشريط الجانبي (يمين الشاشة في العربية).
3. ارسم بالفأرة أو اللمس. يُحفظ العمل تلقائيًا في المتصفح.

## الأدوات

| الأداة | الاختصار | الوصف |
|--------|----------|--------|
| تحريك | H | تحريك اللوحة |
| تحديد | V | تحديد وتحريك وتحجيم |
| مستطيل / معيّن / بيضاوي | R / D / O | أشكال |
| خط / سهم | L / A | خطوط |
| سهم زاوية | X | سهم متعامد (مخططات) |

| نص | T | كتابة عربية أو إنجليزية |
| صورة | I | إدراج صورة (أو Ctrl+V) |
| ملاحظة | N | ملاحظة لاصقة |
| إطار | F | إطار/شريحة |
| تعبئة | B | تعبئة الأشكال |
| ليزر | S | مؤشر عرض |
| ممحاة | E | حذف عنصر |

## التحديد المتعدد

- **Shift + نقر** لإضافة عناصر للتحديد.
- اسحب على فراغ اللوحة لتحديد منطقة.
- **Ctrl + A** لتحديد الكل.
- عند تحديد عنصرين أو أكثر: محاذاة/توزيع، **G** تجميع، **Shift+G** إلغاء، **K** قفل، **[** / **]** تدوير.
- الأسهم ترتبط تلقائيًا بالأشكال القريبة.
- اضغط **Delete** لحذف المحدد.

## أدوات متقدمة

- **لوحة الأوامر**: `Ctrl+K` أو `⌘K` — بحث وتنفيذ أوامر الواجهة.
- **وضع الزن**: إخفاء الأدوات للتركيز على اللوحة.
- **وضع العرض فقط**: قفل التحرير (يصلح للمشاركة).
- **Mermaid**: استيراد مخططات تدفق بسيطة (flowchart TD/LR).
- **العرض التقديمي**: الإطارات كشرائح · أسهم لوحة المفاتيح · Esc للخروج.
- **المكتبة**: بحث وتصنيفات (زخرفة/تدفق/مكتبية/تعليمية/مخصص).
- **إطارات وأسهم زاوية وروابط وليزر وتعبئة** كما في المرحلة السابقة.
- **إحصاءات** و**خريطة مصغرة**.

## البحث في النصوص

حقل **بحث** في الشريط العلوي يُظلل النصوص المطابقة على اللوحة (يدعم العربية).

## النصوص العربية

- الخطوط **مضمّنة ذاتيًا** في التطبيق (Cairo، نسخ، ليمونادة، شنجة، ريم كوفي، عارف رقعة، أميري).
- عند الكتابة بالعربية يُختار خط عربي تلقائيًا.
- نقرة مزدوجة على النص لتحريره.

## مكتبة الأشكال العربية

قوالب جاهزة: بسملة وزخارف، مخططات تدفق، بطاقات، خطوط عربية، جداول صفية.
- **حفظ التحديد في المكتبة** يضيف قوالبك (محليًا + خادم التخزين).

## المشاركة والتعاون

1. اضغط **بدء تعاون** لإنشاء غرفة مشفّرة.
2. انسخ الرابط وأرسله — المفتاح في جزء `#` من الرابط.
3. **رابط قراءة فقط** للمشاركة دون تعديل.
4. **لوحة المشاركون**: الأسماء، الحالة (نشط/خامل)، **متابعة** لعرض شاشة الزميل.
5. **تغيير الاسم** من نفس اللوحة.
6. التراجع أثناء التعاون يؤثر على تعديلاتك المحلية فقط (لا يلغي عمل الآخرين).
7. عند حفظ عنصر في المكتبة داخل غرفة تُحفظ أيضًا في **مكتبة الغرفة**.

### الاستضافة الذاتية

```bash
npm run start:stack
# أو
docker compose up -d
```

- غرفة التعاون: منفذ 3002
- التخزين: منفذ 8080
- الواجهة: 3001 للتطوير / 8088 في Docker

### الأمان

- المشهد مشفّر طرفًا بطرف (AES-GCM).
- رموز وصول متعددة: `STORAGE_AUTH_TOKENS`.
- محركات التخزين: ملفات، ذاكرة، S3، PostgreSQL.
- التفاصيل في `SECURITY.md`.

## التصدير

- **PNG** — صورة اللوحة.
- **SVG** — ملف قابل للتحرير مع دعم النص العربي.
- **SVG*** — التحديد فقط.

## العمل دون اتصال

يمكن تثبيت التطبيق (PWA) ومتابعة الرسم دون إنترنت. المشاركة والتعاون يحتاجان خادم الغرفة.

## اختصارات إضافية

- **Ctrl+Z** تراجع · **Ctrl+Y** إعادة · **Ctrl+G** تجميع
- **G** / **Shift+G** تجميع · **K** قفل · **[** / **]** تدوير
- عجلة الفأرة: تمرير · **Ctrl+عجلة**: تكبير
