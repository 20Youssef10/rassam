# Branding — رسَّام (Rassam)

## Name

| Language | Name | Meaning / Notes |
|----------|------|-----------------|
| Arabic   | رسَّام | “Painter / Drawer / Artist” — the one who draws |
| English  | Rassam | Transliteration, easy to pronounce and search |

The Arabic name is primary. The English name is used in code, domains, and international contexts.

**Tagline ideas**
- العربية أولًا
- ارسم بالعربية
- السبورة العربية المفتوحة
- Hand-drawn diagrams, Arabic-first

## Logo & Visual Identity

- Primary mark: stylized Arabic letter or calligraphic “ر” combined with a simple hand-drawn stroke / pencil motif.
- Should work in monochrome and in the brand color palette.
- Favicon, app icon (PWA), and social images must exist in both light and dark variants.
- Avoid using the official Excalidraw logo or any confusingly similar mark.

## Color Palette

## Typography

### Arabic

Primary Arabic fonts (in order of preference for UI):
1. **Cairo** / Cairo Play — modern, excellent readability
2. **Noto Naskh Arabic** — classical, highly legible
3. **Lemonada** — friendly, slightly rounded
4. **Changa** — strong display
5. Handwriting / free-draw style fonts for the canvas experience

### Latin

- System UI stack or Inter / similar for any remaining Latin UI strings.
- Canvas text uses the same font picker as Excalidraw, extended with the Arabic set.

### Rules

- Arabic text in the UI uses the Arabic font stack.
- Mixed Arabic + Latin content prefers the Arabic font with good Latin fallbacks.
- Minimum body size for Arabic UI: 16 px (Arabic script benefits from slightly larger sizes).

## Voice & Tone

- Clear, direct, and respectful.
- Prefer simple Modern Standard Arabic for UI.
- Avoid overly formal or archaic language.
- English documentation can be more technical; Arabic documentation should stay accessible.
- Celebrate the act of drawing and thinking visually in Arabic.
